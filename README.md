Aesthetic pastel-themed productivity web app to create and manage your to-do lists.
ScribbleSpace helps you organize tasks in a clean, minimal, and calming interface inspired by soft pastel designs.

Features:-
📝 Create multiple task lists
➕ Add tasks instantly
🗑 Delete tasks
🎨 Pastel gradient UI
🌫 Blurred aesthetic background
📱 Responsive layout

🖥 Tech Stack
HTML5
CSS3
JavaScript
